# 약 알람 (갤럭시 / 안드로이드)

약 이름과 시간을 등록하면, 그 시간에 **약 이름을 음성으로 10번 외치고**,
끄기 전까지 **1분마다 다시 10번씩** 외치는 복약 알람 앱입니다.

## 기능
- 약 이름 + 시간 입력 → 매일 같은 시간에 알람
- 알람이 울리면 약 이름을 10번 외침 (진동 함께), 끌 때까지 1분마다 반복
- 잠금 화면 위에 큰 **끄기** 버튼 화면 표시 / 알림창의 **끄기** 버튼
- 같은 시간 약이 여러 개면 이름을 이어서 외침 ("혈압약, 당뇨약")
- 목록에서 **옆으로 밀면 삭제** (실수하면 '되돌리기')
- 오른쪽 위 **모두 삭제** 버튼
- 목록의 약을 누르면 이름을 한 번 미리 들어볼 수 있음
- 휴대폰을 껐다 켜도 알람 유지

## APK 만드는 방법

### 방법 1: Android Studio (PC)
1. https://developer.android.com/studio 에서 Android Studio 설치
2. `File → Open` 으로 이 `YakAlarm` 폴더 열기 (처음엔 다운로드로 몇 분 걸림)
3. 메뉴 `Build → Build App Bundle(s) / APK(s) → Build APK(s)`
4. 생성 위치: `app/build/outputs/apk/debug/app-debug.apk`
   - 휴대폰을 USB로 연결했다면 ▶ Run 버튼으로 바로 설치도 가능

### 방법 2: GitHub (Android Studio 설치 없이)
1. GitHub에 새 저장소를 만들고 이 폴더 내용을 그대로 업로드
2. 저장소의 **Actions** 탭 → "Build APK" 작업이 자동 실행 (약 5분)
3. 완료된 작업을 눌러 아래 **Artifacts → yak-alarm-apk** 다운로드 (zip 안에 APK)

## 휴대폰에 설치
1. APK 파일을 휴대폰으로 옮겨서 누르기
2. "출처를 알 수 없는 앱 설치" 허용
3. 처음 실행 시 나오는 권한 안내(알림, 전체 화면 알림, 배터리 제한 해제)를 모두 허용

## 갤럭시에서 꼭 확인할 것
- **알람 볼륨**: 음성은 *알람 볼륨*으로 나옵니다 (설정 → 소리 및 진동 → 음량 → 알람)
- **배터리**: 설정 → 애플리케이션 → 약 알람 → 배터리 → **제한 없음**
- 음성이 안 나오면: 설정 → 일반 → 글자 읽어주기(TTS) → 기본 엔진이 삼성/Google, 언어가 한국어인지 확인
  (음성 엔진이 없으면 기본 알람음이 대신 울립니다)
